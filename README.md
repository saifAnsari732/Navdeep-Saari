# NAVDEEP — Kanchipuram Silk Sarees

**Woven for the Divine.**  
An interactive, animation-rich luxury Kanchipuram silk saree experience built with **Next.js 15 (App Router)**, **Framer Motion 12**, **GSAP 3**, **Lenis Smooth Scroll**, and **Tailwind CSS 4**.

## Key Features & Sections
- **Crimson Zari Silk Curtain Intro** — Ornamental Kanjivaram silk curtain reveal on initial load.
- **Scroll-Pinned Showroom Walkthrough** — 220vh sticky scroll-driven camera glide through the NAVDEEP heritage showroom.
- **Floating Liquid-Glass Navbar** — Custom Sacred Deepam-Lotus gold emblem, scroll-tracking active pill (`layoutId`), live Silk Bag & Wishlist counters, and private store appointment modal.
- **Six Moods (`The NAVDEEP Archive`)** — Six saree editorials framed inside custom SVG Gopuram temple-arch windows with golden finials.
- **Try the Look** — Spring-physics drag/click studio runway carousel paired with a 6-piece shoppable bundle calculator (10% automatic savings).
- **Pick a Silk** — Fanned arc of bold jewel-toned saree cards with giant condensed poster typography behind true transparent model cutouts and real-time 3D cursor tilt + specular glare.
- **The Rack (`Every silk, on the rail`)** — Brushed chrome clothes rail with 17 studio pieces (Silk Sarees, Half Sarees / Langa Voni, Full-Sleeve & Half-Sleeve Silk Blouses, Checked Sarees, Zari & Brocade) on natural walnut hangers + full-focus lifted detail overlay with 3D Front/Back weave inspection flip.
- **Draped in Devotion** — Snap-scrolling numbered editorial gallery + poetic italic serif marquee ribbon.
- **The Muse Film & Muse Reels** — 16:9 gold-bracketed film stage with Web Audio ambient tanpura sound toggle + 3D curved perspective reel arc with Stories-style fullscreen lightbox.
- **The Bridal Collection & Three Silks (`Seer Varisai`)** — Curved arch-topped bridal carousel + live 60fps HTML5 Canvas 3-strand sinusoidal silk braid bundle builder.

## Getting Started

